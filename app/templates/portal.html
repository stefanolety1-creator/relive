Cos'è il Progetto ReLive?

Negli anni 2000, Windows Live Essentials è stato il cuore pulsante dell'esperienza Windows. Con la chiusura dei server Microsoft, molte applicazioni hanno smesso di funzionare. ReLive nasce per ripristinare l'infrastruttura di rete originale.

📷

Raccolta Foto Windows Live

L'organizzatore fotografico più amato. Grazie a ReLive puoi effettuare il login autentico con il tuo Windows Live ID, gestire i tag persone e pubblicare i tuoi album direttamente su SkyDrive.

✓ Supportato al 100%
☁️

Windows Live SkyDrive

25 GB di spazio cloud integrato con l'API di Google Drive. Puoi caricare documenti, foto e cartelle sia via interfaccia web retrò che direttamente dalle app desktop della suite.

✓ 25 GB su Google Drive
✉️

Windows Live Mail

Il client di posta desktop con sincronizzazione calendario e contatti. ReLive implementa l'endpoint DeltaSync e SMTP per inviare e ricevere posta con il tuo dominio @live.it.

✓ DeltaSync • SMTP
✍️

Windows Live Writer

L'editor WYSIWYG per blog. Supporta MetaWeblog API con caricamento istantaneo delle immagini e formattazione tipografica identica a quella stampata.

✓ MetaWeblog API
💬
Windows Live Messenger → Escargot Chat

Per il servizio di messaggistica istantanea (MSN / Windows Live Messenger) consigliamo vivamente l'utilizzo della straordinaria rete di Escargot Chat. ReLive si concentra sul far rivivere il resto della suite Windows Live Essentials, integrandosi armoniosamente con l'ecosistema esistente.
